# FanGuard

极简的 macOS 菜单栏工具：静默监测**风扇转速**与**芯片温度**，在电脑异常发热或风扇突然高速运转时，自动聚合分析高负载源头应用并及时提醒，由你自主决定结束进程或忽略。

## 核心特性

- **静默后台运行**：常驻顶部菜单栏小图标（无 Dock 图标），平时不打扰；异常时高亮显示转速与温度。
- **风扇 + 温度联合监测（无需 `sudo`）**：
  - 通过 `AppleSMC` 读取实时风扇转速（RPM）。
  - 通过 `IOHIDEventSystemClient` 读取 Apple Silicon `PMU tdie*` 芯片核心温度（平均/峰值）与电池温度。
- **按应用聚合分析源头**：自动将同一个应用下的多个子进程（如浏览器 Helper / Renderer）聚合计算，结合近 30 秒持续均值排序。
- **极简交互面板**：
  - 仅保留应用图标 + 图标化指标（进程数 / CPU% / 内存），隐藏冗长程序名。
  - 鼠标悬停在任意行上即时浮现应用名称与高负载原因说明。
  - 支持深色 / 浅色模式自适应。
  - 提供「忽略（30分钟）」「结束（支持 Option 强制结束）」「在访达中显示」以及三档报警阈值（敏感 / 标准 / 高负载）。

## 构建运行

环境要求：macOS 13.0+，已安装 Xcode Command Line Tools（`clang`）。

```bash
./build.sh
open build/FanGuard.app
```
